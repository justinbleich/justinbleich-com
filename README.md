# Justin Bleich

Lightweight React clone of [justinbleich.com](https://www.justinbleich.com/) built with Vite.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vercel can deploy this repository with the default Vite settings:

- Build command: `npm run build`
- Output directory: `dist`
